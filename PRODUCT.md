# Harness Lab

## Register

product

## Users

A mixed audience learning agent harnesses through approachable lessons and expandable technical details. Confirmed by the user during setup.

## Product Purpose

Make the software around an LLM observable and editable. Read a short concept, run an experiment, change one control, and inspect how behavior changes. Support custom scenarios, durable memory, a credential-free simulator, and live OpenAI GPT-5.6 Sol.

## Brand Personality

Calm, precise, curious. The user chose a calm, precise learning lab.

## Anti-references

Avoid unexplained terminal dumps, marketing dashboards, and decorative complexity that obscures the lesson. These follow the selected learning-lab direction.

## Design Principles

- Explain the mechanism before the implementation detail.
- Make cause and effect inspectable.
- Put harness configurations at the center of comparisons: explicit feature On/Off controls, visible differences, and observed behavior under each version. Execution diagrams are optional inspection details.
- Distinguish model decisions from enforced software rules.
- Label simulation and live behavior honestly.
- Keep advanced controls available without making them the first lesson. All version settings belong in aligned comparison rows; use one shared collapsible section instead of per-version configuration popups.

## Accessibility & Inclusion

Keyboard access, readable contrast, semantic controls, and reduced-motion support as proposed and accepted during setup. Target WCAG AA.
